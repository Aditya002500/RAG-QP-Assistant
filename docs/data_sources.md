# VTU Data Sources & Indexing Documentation

## 1. Overview

VTU Study Assistant indexes syllabus documents and previous-year question papers (PYQs) for:
- **Scheme**: 2022 Scheme (CBCS)
- **Branch**: Computer Science & Engineering (CSE)
- **Semester**: 5th Semester

## 2. Subjects Covered

| Subject Code | Subject Name | Type | Modules | Credits |
|---|---|---|---|---|
| `21CS51` | Software Engineering & Project Management | Core Theory | 5 Modules | 3 |
| `21CS52` | Computer Networks | Core Theory | 5 Modules | 4 |
| `21CS53` | Database Management Systems | Core Theory | 5 Modules | 4 |
| `21CS54` | Artificial Intelligence & Machine Learning | Core Theory | 5 Modules | 3 |

## 3. Previous-Year Question Papers (PYQs)

The index includes authentic examination question papers spanning 3 academic sessions:
1. **Dec 2022 / Jan 2023** (Winter Session)
2. **June / July 2023** (Summer Session)
3. **Dec 2023 / Jan 2024** (Winter Session)
4. **June / July 2024** (Summer Session)

## 4. File Naming Convention

As specified in the PRD, raw PDFs adhere to the convention:
`<scheme>_<branch>_<sem>_<subjectcode>_<doctype>_<year>.pdf`

Examples:
- `2022_CSE_5_21CS51_syl.pdf` (Syllabus for 21CS51)
- `2022_CSE_5_21CS51_pyq_2023.pdf` (PYQ for 21CS51 - Jan 2023)
- `2022_CSE_5_21CS52_pyq_2024.pdf` (PYQ for 21CS52 - July 2024)
